## How to use it

This is the repository where we store our code after completing our section.

### Instructions

1. Clone the repository.
2. Copy each file to its corresponding folder.

Example:  
`unsw_analyzer.py` must be placed inside the **UNSW-NB15 dataset folder**.

3. Open each file and adjust the dataset path in the code if necessary.

Note:  
If you are using Linux, the default paths may work.  
If you encounter any problems, it is probably related to the dataset path. Just modify it according to your system.

4. Run the script and everything should work.

---

## Workflow

After finishing your code:

1. Copy your final code back into the cloned repository.
2. Use the appropriate Git commands to push your changes to GitHub.
3. Make sure to **document your code** so everyone can understand it.
